# Объектно-ориентированное программирование (ООП)

## Сборка и запуск тестов

Проект собирается Maven-ом и состоит из пяти модулей — по одному на задачу (`task01` … `task05`).
Требуется JDK 8 и выше и Maven 3.6+.

```bash
mvn test              # прогнать тесты всех задач
mvn -pl task01 test   # прогнать тесты одной задачи
```

Тесты каждой задачи лежат в `taskNN/src/test/java`, решение пишется в `taskNN/src/main/java`.
